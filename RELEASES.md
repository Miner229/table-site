# Выпуски и откат

Каждая версия, выложенная на сайт, сохраняется как **метка `release-ГГГГ-ММ-ДД-ЧЧММ`** (время Актобе) в GitHub.
Это постоянная резервная копия сайта целиком (табло, судьи, секретарь, скрипт `Code.gs`).

## Откатить сайт (1 минута)

```bash
tools/rollback.sh                                   # список сохранённых версий
tools/rollback.sh release-2026-11-27-0058 --push    # вернуть сайт к этой версии и опубликовать
```

- Ничего не удаляется: откат — это новый коммит с файлами точно как в выбранной версии.
  Чтобы отменить откат, так же «откатитесь» на более новую метку.
- Через ~1 минуту сайт обновится; на экране в зале нажмите **Ctrl+F5**.
- Если скрипта нет под рукой (откатились на очень старую версию):
  `git show release-<новая>:tools/rollback.sh > /tmp/rb.sh && bash /tmp/rb.sh <метка> --push`

## Откатить скрипт Google (Apps Script)

Скрипт выкладывается отдельно от сайта. Откат без правки кода:
Расширения → Apps Script → **Начать развертывание → Управление развертываниями → ✏️ →
Версия: выбрать предыдущую → Развернуть**. Адрес веб-приложения не меняется.

| Версия скрипта | Когда | Что |
|---|---|---|
| Version 1 | 25.11 | до «оценка один раз» |
| Version 2 | 27.11 00:06 | оценка один раз, код секретаря, `state`, очистка тестовых оценок при старте (`Code.gs` из `release-2026-11-27-0003`) |

## Откатить данные в Google-таблице

Файл → **История версий** → выбрать время → «Восстановить». Google хранит её сам.

## Сохранить новую версию (после каждого выкладывания на сайт)

```bash
tools/save-release.sh "что изменилось"
```

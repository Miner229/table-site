# ArtVin Cup — настройка табло и кодов судей

Всё работает от **одной Google-таблицы** (та же, что сейчас: `1NCLssbli5uUVMNLn88zw8n2RdzHTaZrumR9AP0Zvd9w`).

```
Судья (телефон) ──► judge.html ──► Apps Script ──► Google-таблица ──► табло в зале
  вводит код        только свой снаряд  проверяет код     ▲          + ссылка для родителей
                                                          └── протокол секретаря → выгрузка в Excel
```

## Куда идут оценки

- **Хранятся в Google-таблице** — вкладка потока, колонка снаряда, строка гимнаста. Это и есть протокол.
  Сумма считается формулой в колонке «Сумма». Каждое изменение дополнительно пишется во вкладку «Журнал».
- **Google-таблица нужна обязательно**: в неё одновременно пишут судьи со всех снарядов, и из неё
  каждые ~10 с читают табло, телефоны родителей и секретарь. Файл Excel на компьютере так работать не может.
- **Excel — для итогов**: Google-таблица → Файл → Скачать → Microsoft Excel (.xlsx), или кнопка
  «Скачать для Excel» на странице секретаря (все оценки, сумма, места). Для награждения и печати.

## 1. Вкладки в таблице

Старые вкладки «поток 1…7» не трогаем — их читает текущая главная страница.
Добавляем новые (можно импортировать из файла `ArtVin Cup — таблица для сайта.xlsx`:
Файл → Импорт → «Вставить новые листы»).

**«Настройки»** — одна строка на поток:

| Поток | Лист | Пол | Ротация | Режим | Время ротаций | На экране | Начало |
|---|---|---|---|---|---|---|---|
| Пятница · Поток 1 | Пятница 1 | М | 1 | авто | 08:00 08:35 09:10 … | | 27.11.2026 08:00 |

- **Пол**: М — 6 снарядов, Ж — 4 (прыжок, брусья, бревно, вольные).
- **Режим ротации**:
  - `ручной` — табло переходит, когда меняете цифру в «Ротация»;
  - `авто` — группы переходят сами, когда выставлены все оценки текущей ротации (цифра «Ротация» работает как минимум — ею можно «подтолкнуть» вперёд);
  - `время` — по расписанию из «Время ротаций».
- **Начало** — дата и время старта потока, например `27.11.2026 08:00` (время Актобе). Потоки переключаются сами, см. раздел 5.
- **На экране** = `да` — ручное управление: если `да` стоит хоть у одного потока, показывается он, а «Начало» не действует.
- Все времена («Начало», «Время ротаций») — **время Актобе (UTC+5)**, на любом устройстве, даже если часы на нём в другом поясе.

**Вкладка потока** (например «Пятница 1»), заголовки в первой строке:

`№ | ФИО | Год | Клуб | Старт | Вольные | Конь | Кольца | Прыжок | Брусья | Перекладина | Сумма`

- **Старт** — снаряд, с которого начинает группа. Вместо колонки можно ставить строку-разделитель с названием снаряда (как в стартовых листах) — все ниже начинают с него.
- Детей можно добавлять и удалять в любой момент — сайт ищет колонки по заголовкам.
- Строки-разделители можно писать как в стартовых листах: «Вольные упражения», «Параллельные Брусья », «Опорный Прыжок»,
  «Разновысокие брусья» — регистр, лишние пробелы и опечатка «упражения» не мешают. Фамилия вроде «Вольнов Иван» разделителем не считается.
- **Импортированные стартовые листы** (только № | ФИО | Год | Разряд | Регион/Клуб): меню **ArtVin Cup → Подготовить вкладки потоков**
  допишет справа недостающие колонки оценок (М: Вольные, Конь, Кольца, Прыжок, Брусья, Перекладина; Ж: Прыжок, Брусья, Бревно, Вольные)
  и «Сумма» во все вкладки из «Настроек». Существующие ячейки не меняются; повторный запуск ничего не добавляет.
- Оценка — от 0 до 10 (до 3 знаков после запятой). «Не выступал» = `0` (на табло: «н/я»).

## 2. Доступ

Настройки доступа → «Все, у кого есть ссылка» → **Читатель**. Судьям права редактирования **не давать**.

## 3. Скрипт для судей

1. Расширения → Apps Script → вставить `Code.gs` → Сохранить.
2. Начать развертывание → Новое развертывание → тип **Веб-приложение**, «Запуск от имени: **Я**», «Доступ: **Все**» → Развернуть → разрешить доступ.
3. Обновить таблицу → меню **ArtVin Cup → Коды судей**. Там:
   - **одна ссылка для всех судей** (страница входа);
   - **8-значный код для каждого снаряда** (М — 6 кодов, Ж — 4 кода).
4. Каждому судье — общую ссылку и **только код его снаряда**. Судья открывает ссылку, **выбирает свой снаряд
   и вводит его код** → видит только свой снаряд. (Можно дать и ссылку конкретного снаряда — сразу откроется
   поле для кода.) С этим кодом поставить оценку на другой снаряд нельзя — это проверяет сервер,
   а не страница. Код запоминается на телефоне до кнопки «Выйти».
5. Если код попал не тому — **ArtVin Cup → Создать новые коды** (старые сразу перестанут работать;
   код организатора тоже меняется).

**После изменения Code.gs** (новая версия из репозитория): вставьте его в Apps Script → Сохранить →
**Начать развертывание → Управление развертываниями → ✏️ → Версия: «Новая версия» → Развернуть**.
Адрес веб-приложения не меняется, ссылки судей продолжают работать.
   Удобно менять коды перед каждым днём соревнований.

Логинов и паролей Google судьям не нужно. Доступа к самой таблице у судей нет.

Каждая оценка записывается во вкладку **«Журнал»** (время, снаряд, ФИО, было → стало).

## 4. Как идёт поток (авто-режим)

1. Ротация 1: каждая группа (≈10 человек) на своём снаряде. Табло показывает по снаряду, судьи видят только свою группу.
2. Судья выставил всю свою группу → у него «Ваша группа готова ✓, ждём другие снаряды».
3. Когда **все** снаряды закончили, группы переходят на следующий снаряд:
   - у судей список сразу меняется на новую группу;
   - табло ~60 с показывает итог ротации, затем заставка «РОТАЦИЯ 2» и таблицы с новыми группами (оценки пустые — «ожидает»);
   - все предыдущие оценки остаются в Google-таблице и в протоколе секретаря.
4. После последней ротации — «Все снаряды пройдены»: у каждого гимнаста оценка на всех снарядах и сумма.

Если гимнаст не выступает — судья нажимает «Н/Я» (оценка 0), иначе поток будет ждать его оценку.

## 5. Потоки

- Потоков может быть сколько угодно: одна строка в «Настройках» + одна вкладка на поток. Код менять не нужно.
- Одновременно идёт **один поток**. Табло, родители, судьи и секретарь переключаются на него сами, в одну и ту же минуту.

**По расписанию (колонка «Начало»)** — в «На экране» ни у кого нет «да»:

- показывается поток с самым поздним «Началом», которое уже наступило;
- он остаётся на экране с итоговыми результатами, пока не начнётся следующий;
- утром, до первого потока дня, на табло уже следующий поток с надписью «Начало в 08:00»;
- за ~2 минуты до «Начала» табло заранее загружает следующий поток и в нужную минуту меняет его без пустого экрана,
  с заставкой «<поток> · <время>» на 5 секунд.

**Вручную — кнопка «Поток» на табло** (левый нижний угол, бледная надпись «ПОТОК»; или клавиша `P`):

1. Один раз откройте табло на компьютере у экрана по **ссылке организатора** из меню **ArtVin Cup → Коды судей**
   (так табло узнаёт адрес скрипта).
2. Нажмите «Поток», введите **код организатора** (там же, в «Кодах судей»; на этом компьютере он запоминается).
3. Выберите поток, например «Пятница · Поток 1». Табло, родители, судьи и секретарь переключаются на него,
   а **оценки принимаются только в этот поток** — в другие потоки сервер их не запишет.
   Судьи другого пола видят «Сейчас идёт поток …» вместо списка.
4. «По расписанию «Начало»» — снова автоматическое переключение по времени.

Кнопка просто ставит `да` в «На экране» у выбранного потока (и убирает у остальных) — то же можно сделать
руками в таблице. Судьи сами поток не выбирают: у них показано только название текущего потока.

На отдельном экране можно выбрать поток в списке вверху справа; «●» — снова автоматически.

### Расписание 27–29 ноября 2026 (готово для вставки)

Заполните «Пол» и при необходимости поправьте названия; «Лист» должен совпадать с названием вкладки.

| Поток | Лист | Пол | Ротация | Режим | Время ротаций | На экране | Начало |
|---|---|---|---|---|---|---|---|
| Пятница · Поток 1 | Пятница 1 | | 1 | авто | | | 27.11.2026 08:00 |
| Пятница · Поток 2 | Пятница 2 | | 1 | авто | | | 27.11.2026 12:15 |
| Суббота · Поток 1 | Суббота 1 | | 1 | авто | | | 28.11.2026 07:30 |
| Суббота · Поток 2 | Суббота 2 | | 1 | авто | | | 28.11.2026 11:15 |
| Суббота · Поток 3 | Суббота 3 | | 1 | авто | | | 28.11.2026 15:00 |
| Суббота · Поток 4 | Суббота 4 | | 1 | авто | | | 28.11.2026 18:30 |
| Воскресенье · Поток 1 | Воскресенье 1 | | 1 | авто | | | 29.11.2026 11:30 |
| Воскресенье · Поток 2 | Воскресенье 2 | | 1 | авто | | | 29.11.2026 15:00 |
| Воскресенье · Поток 3 | Воскресенье 3 | | 1 | авто | | | 29.11.2026 18:30 |

Если Google-таблица сама превращает «27.11.2026 08:00» в дату — это нормально, сайт читает и такой вид.

### Проверка расписания

На табло нажмите `S` → блок **«Потоки · время Актобе»**: все потоки с «Началом», отмечено, какой **идёт**
и какой **следующий**. Красным — нет «Начала», непонятная дата, одинаковое время у двух потоков,
нет такой вкладки (кнопка «Проверить вкладки»).

- У каждого потока своя ротация и свои оценки — потоки не влияют друг на друга.
- Если связь с таблицей пропала, табло, судьи и секретарь продолжают показывать последние данные и сами
  пробуют снова; через ~60 с без связи появляется маленькая надпись «Нет связи». Набранные судьёй оценки не теряются.

## 6. Если два устройства на одном снаряде

Если оценку уже изменили на другом устройстве, сохранение не пройдёт: судья увидит новое значение
и сможет исправить его ещё раз осознанно. Так одна оценка не затрёт другую незаметно.

## 7. Экран

- Шрифт 42 px; на невысоких экранах он сам уменьшается так, чтобы помещалось **не меньше 10 участников**
  (настройка «Минимум участников на экране», клавиша `S`).
- Показывается только **1-е место** (золотом); у остальных мест номеров нет — только порядок по оценкам.
  Так же на странице секретаря. Полные места остаются в выгрузке для Excel (для награждения).
- Красные строки «⚠» в настройках экрана, у судьи и у секретаря — проблемы в таблице
  (нет колонки снаряда, гимнаст без стартового снаряда, повтор ФИО).
